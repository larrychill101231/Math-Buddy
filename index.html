Code Explorer: How It Works!

Hey there! 👋 Ever wonder how this calculator actually works? Let's break it down! Think of a website like a body. It has a skeleton, skin, and a brain.

HTML is the Skeleton 🦴

HTML stands for HyperText Markup Language. It builds the structure of our app. Just like bones hold you up, HTML tags hold up the website!

<div>

Think of a div as an invisible box. We use lots of these boxes to group things together, like grouping all the calculator buttons into one big box.

<button>

This creates something you can click! Every number and math symbol on our calculator is a button.

<div id="main-display">

This is a special box where we show the numbers you type. We give it an id so our JavaScript brain can easily find it later!

CSS is the Skin 🎨

CSS makes things look good! It's like painting your house or choosing an outfit. We use a cool tool called Tailwind CSS.

Colors & Looks

Classes like bg-primary make a button blue, and rounded-lg makes the corners smooth instead of pointy.

Grid Layout

See how the buttons are perfectly lined up? We use grid grid-cols-4. It tells the browser, "Make a grid with 4 equal columns!"

Flexbox

We use flex to easily center things or put them side-by-side. It's super flexible (that's why it's called flex!).

JavaScript is the Brain 🧠

JavaScript makes the calculator actually do math! Without it, clicking buttons would do absolutely nothing.

Variables (Memory)

We use let expression = '' to remember what you typed. It's like the calculator's short-term memory.

append()

When you click a button, this function runs. It takes the number you clicked and adds it to our memory.
"Oh, you clicked 7? I'll add that to the screen!"

clearScreen()

This simply deletes our memory, changing the expression back to empty so we can start over.

calculate() & eval()

The magic trick! When you hit equals, we use a special built-in tool called eval(). It takes a string of text like "2+2" and solves it instantly!
